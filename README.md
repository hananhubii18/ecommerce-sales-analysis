# E-Commerce Sales Data Analysis

## 📊 Project Overview

This project analyzes e-commerce sales data using Python to understand sales performance, customer behavior, product performance, and profitability.

The project uses data analysis and visualization techniques to identify important business trends and generate meaningful insights from the dataset.

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

---

## 📁 Dataset

The dataset contains **3,500 e-commerce orders** covering the period from **2025 to 2026**.

It includes information such as:

- Order date
- Product
- Category
- Quantity
- Unit price
- Discount
- Revenue
- Cost
- Profit
- Region
- City
- Customer segment
- Payment method
- Order status

> **Note:** This is a synthetic dataset created for educational and portfolio purposes. It does not represent real company or customer data.

---

## 📈 Analysis Performed

The project performs several types of analysis, including:

### Sales Analysis
- Monthly revenue trends
- Revenue by product category
- Revenue by region
- Revenue by city
- Top-performing products

### Customer Analysis
- Customer segment analysis
- Payment method analysis
- Order status distribution

### Profitability Analysis
- Total revenue
- Total profit
- Profit margin
- Profit by category
- Profit margin by category

### Data Visualization
- Line charts
- Bar charts
- Pie charts
- Scatter plots
- Histograms
- Correlation heatmap

---

## 💡 Key Insights

The analysis identifies:

- Top-performing products based on revenue
- Best-performing product categories
- Regional and city-wise sales performance
- Customer segments generating the highest revenue
- Most commonly used payment methods
- Monthly revenue trends
- Relationship between quantity, discount, and revenue
- Profitability differences between categories

---

## 📊 Key Performance Indicators

The analysis calculates important business metrics such as:

- Total Orders
- Delivered Orders
- Products Sold
- Total Revenue
- Total Profit
- Average Order Value
- Overall Profit Margin
